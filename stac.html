STAC SIMULATION FOR AUTONOMOUS RESOURCE ROVER  
Link to STAC website: https://stac.berkeley.edu/project/rover Partnership with NASA Ames Research Center Autonomous resource rover Involves mechanical rover design, autonomous work in making rover move on its own My part - simulation technology for an environment to test algorithms + ML models for autonomous decision making Team: Autonomous
Tools: ROS (Robot Operating System), Gazebo, Docker BEGINNING OF SIMULATION We had a Gazebo GUI running as an app, on one Linux machine. Goal - make an environment that can be used on any machine, setup quick CONSIDERATIONS Needed a GUI, could not be done in terminal Needed to see a rover and its environment visually to understand its actions Virtual Machine vs Docker vs Cloning a Github repo Can't clone - OS specific problems (Mac vs Windows vs Linux) VM - uses a lot of machine's resources Decided on Docker DOCKER DEVELOPMENT Docker would install all packages and be the central environment Would start a local barebones Ubuntu environment User would VNC to Docker container (needed for GUI) RESULT github clone docker repo start container (with assets and local ML models in a volume mounted to container) vnc in web broswer tada!
