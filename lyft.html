LYFT DATA INTELLIGENCE IN 21ST CENTURY TRANSPORTATION  
As a summer intern at Lyft, I worked on the Data Tools and Visualization team, which sits as a team bridging Data Platform with various organizations within Lyft that need to easily access and use data and relevant pipelines.

My project was in building an internal tool for data discovery. Data discovery is a group of problems dealing with how to find the right data, given a question to answer or a problem to solve. For example, if I wanted to know how many Lyft rides the average user in San Francisco took, I would have to search for a database and a table that held information about each ride, a user id, and their location.

However, with the number of data resources in Lyft growing by the day, it becomes hard for one person, or even a group of people, to understand all the data resources within Lyft and which tables can address which questions. Furthermore, even if they had absolute knowledge, it is hard for them to always be available for every person within the company who needs to find data. This is the core problem that our internal tool was addressing.
